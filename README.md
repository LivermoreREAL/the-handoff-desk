# The Handoff Desk

Static site for The Handoff Desk (Sam Yusufi): marketing assets, listing coordination, and transaction coordination for California agents.

- `index.html`: the whole page.
- `assets/`: images.
- `_form/`: Google Apps Script that emails request-form submissions to sam@samyusufi.com. See `_form/README.md`.

Deployed on Vercel from the `main` branch.
